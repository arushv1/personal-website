# Portfolio photos

Upload your own photos into folders such as `projects/threshold/` and `awards/urop-poster/`.
Reference them in `src/content/portfolio.mjs` with `/photos/...` URLs (omit `public`).

See [CONTENT.md](../../CONTENT.md#add-photos-to-a-project-or-award) for the photo schema and GitHub instructions.
No stock or placeholder photos are published with the site.
